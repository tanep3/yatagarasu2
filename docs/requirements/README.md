# 要件

要件は観測可能な結果と受入条件を定めます。明示的な制約でない限り、通信方式、製品、プロセス配置、内部機構を選びません。設計の理由は[アーキテクチャ](../architecture/README.md)に、拘束力を持つ判断とその適用範囲は[ADR](../adr/README.md)にあります。

IDは少数で不変です。要件が変わってもIDを使い回さず、置換後の要件へ新しいIDを付け、旧要件は履歴上で廃止します。
