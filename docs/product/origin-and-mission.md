# なぜ、見守りカメラをロボットにするの？

見守りカメラを眺めていると、不思議なことに気づきます。

そこには、周囲を見るためのカメラがある。人の声を聞くためのマイクがある。こちらへ声を返すためのスピーカーもある。

目と、耳と、口。これは、Yatagarasuという名前を支える三本の足です。

そして実は、この三つはスマートグラスともよく似ています。どちらも世界を見て、人の声を聞き、AIの答えを人へ返すための身体です。違うのは、その身体が眼鏡なのか、見守りカメラなのかということ。見守りカメラなら、自分で首を動かして視点まで変えられます。

だったら、カメラへ便利な機能を継ぎ足すだけで終わらせず、身体、感覚、会話、記憶、AIをきちんと結び付ける共通の土台を作れないだろうか。

現在のロボットには、身体の制御を支えるROSがあります。一方で、何を見たのか、何を聞いたのか、何を考え、どの行動を選び、その結果をどう受け止めるのか。そうしたロボットの神経と思考を支える共通基盤は、まだ十分に確立されていません。

Yatagarasu 2は、その原型を目指します。今すぐ完成したOSを名乗るつもりはありません。まずは一台のロボットを正しく、速く、気持ちよく動かす。その実践から、本当にほかのロボットでも使える構造を見つけていきます。
