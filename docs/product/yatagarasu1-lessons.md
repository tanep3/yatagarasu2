# Yatagarasu 1から得たこと

## Yatagarasu 1は、現実を発見した実験機である

Yatagarasu 1は失敗したシステムでも、捨てるべき旧版でもありません。

呼びかけで目を覚ます。人の声を文字にする。SBERTで意味を捉え、単純な身体操作なら重いAIを待たずに反射する。首を動かす。画像を撮り、見たものを考える。会話を記憶し、必要な情報を探し、Skillを使い、自分の声で答える。

Yatagarasu 1は、これらが見守りカメラの身体で本当に一つのロボットになることを実機で証明しました。とりわけSBERTによる意味の反射は、カメラ操作をLLMの長い判断から切り離し、体験速度を大きく変えました。

## 実機だけが教えてくれたこと

現実世界では、正しい命令を書いただけでは終わりません。

- ウェイクワードは誤検出する。
- ロボット自身の発話が、利用者の声として再び聞こえることがある。
- モデルや外部サービスの起動時間が、体験を支配することがある。
- カメラへ動作を頼めても、動き終わったという返事が来ない。
- 音声を送れても、最後まで聞こえたか確認できない。
- 「右を向いて何が見える？」は、移動、待機、撮影、画像解釈、応答からなる複合動作である。
- 利用者が「止まって」と言ったとき、止められる仕事と止められない物理動作がある。
- 記憶、検索、外部AI、音声、カメラは、それぞれ異なる失敗の仕方をする。

これらは単なる不具合一覧ではありません。時間、取消、結果不明、能力の常駐、複合動作、外部障害という、Yatagarasu 2が記述すべき世界の発見です。

## 受け継ぐものと、作り直すもの

Yatagarasu 1は、試し、直し、機能を足すことで世界を発見しました。そのため、発見した知識の一部は時間順の処理へ蓄積しています。しかし、問題は局所的な手続きや条件分岐が存在することではありません。新しい知識が、中央の一つの実行手順へ増え続けることです。

Yatagarasu 2が受け継ぐのは、ウェイクワード、音声、SBERT反射、身体操作、視覚、会話、記憶、音声応答、Skillという機能世界と、実機が発見した制約です。作り直すのは、それらを結んでいた時間順の形です。

Yatagarasu 2では、何が現在の状態か、何が起きた事実か、どの規則が適用できるか、どんな状態変化が許されるか、外界へどんな仕事を頼むかとして再記述します。

そしてYatagarasu 1は、その間も動き続けます。未完成のYatagarasu 2を運用環境へ混ぜない。それは安全対策であると同時に、いまも現実を教えてくれる実験機への敬意です。
