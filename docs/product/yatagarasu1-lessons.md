# Yatagarasu 1から得たこと

Yatagarasu 1は、失敗したシステムではありません。

見守りカメラが声を聞き、呼びかけに目を覚まし、首を動かし、世界を見て、会話を覚え、自分の声で答える。そんなロボットが本当に作れることを、Yatagarasu 1は実機で証明しました。

では、すでに動いているのに、なぜYatagarasu 2を作るのでしょうか。

Yatagarasu 1は、何度も試し、直し、機能を足しながら成長してきました。その過程で、ウェイクワードの誤検出、音声の回り込み、カメラが動き終わったか分からない問題、外部AIや音声サービスの障害など、机の上だけでは見つからない多くのことを教えてくれました。

一方で、発見した知識が増えるほど、それをつないでいる処理も複雑になりました。機能は動いている。でも、このまま機能を足し続ければ、いつか全体を理解することが難しくなる。新しいカメラやAIへ交換するたびに、中央の処理を直すことにもなりかねません。

だからYatagarasu 2では、Yatagarasu 1をそのまま書き直すのではなく、そこで発見した世界をもう一度記述します。

何が現在の状態なのか。何が起きた事実なのか。どんな規則が適用できるのか。どんな変化が許されるのか。外の世界へ、どんな仕事を頼むのか。

受け継ぐのは、実機が教えてくれた知恵と、ロボットとしての魂です。偶然つながっている処理の形まで、そのまま受け継ぐわけではありません。

そしてYatagarasu 1は、この間も動き続けます。未完成なYatagarasu 2を運用中の環境へ混ぜず、別の場所で安全に育てる。それが、すでに生きているロボットへの敬意だと考えています。
