# Yatagarasu 2って、どんなロボット？

一言で表すなら、Yatagarasu 2は「目・耳・口を持つAIロボット」です。

声をかければ、こちらの話を聞く。周囲の様子を尋ねれば、自分の目で確かめる。必要なら身体を動かし、見つけたことを自分の言葉で返す。Yatagarasuが届けたいのは、カメラ、音声認識、AI、スピーカーを寄せ集めただけの機械ではありません。頼む、見る、考える、動く、話すという出来事が、一つにつながったロボット体験です。

## 身体も、頭脳も、成長できる

特定のカメラやAIにしか使えない仕組みでは、そこで成長が止まります。だから目、耳、口、記憶、考えるAIを役割ごとに分け、別のものへ交換できる構造を作ります。

さらにYatagarasuは、ロボットの内側だけで閉じません。Skillは、人が使っているアプリ、そこに蓄えたデータ、アプリが持つ機能をAIへ開く接続面です。Skillが増えれば、Yatagarasuは新しいアプリを理解し、その世界を人と共有し、許された範囲で考察や行動を提案できるようになります。

考える頭脳も一つに固定しません。素早い日常応答、画像を見る能力、難しい推論、ローカルで守りたい処理。SBERTによる意味の反射と方針を使い、依頼に合う頭脳の役割を、LLM自身へ選ばせる前に切り替えます。その役割に、どのAI（LLM）や推論サービス（Provider）を割り当てるかは交換できます。これは単なる設定機能ではありません。速度、能力、プライバシーを一つのロボット体験の中で両立させる、Yatagarasu 2の目玉です。

つまり、身体の交換可能性とSkillによる能力拡張は、開発者だけの都合ではありません。利用者がロボットを、自分の暮らしや仕事に合わせて育てられるための価値です。

## 動く原型から、世界の構造を取り出す

原型のYatagarasu 1はすでに実機で動いています。呼びかけ、音声認識、意味による高速な反射、カメラ操作、視覚、記憶、AI、音声応答、Skillが、一台のロボットとして成立することを証明しました。

Yatagarasu 2は、その機能を一から想像する新規プロジェクトではありません。Yatagarasu 1が発見した機能世界を受け継ぎ、中央の長い手順ではなく、状態と事実と変化の法則として記述し直すプロジェクトです。

## 現在の状態

いまは要件と設計を作っている段階です。動作する配布物や導入手順はまだありません。対応機器、完成時期、外部AIの選び方、記憶やネットワーク公開の方針にも未決事項があります。Yatagarasu 1を動かし続けながら、Yatagarasu 2は別の環境で検証します。
