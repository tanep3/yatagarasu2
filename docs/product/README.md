# Yatagarasu 2って、どんなロボット？

一言で表すなら、Yatagarasu 2は「目・耳・口を持つAIロボット」です。

声をかければ、こちらの話を聞く。周囲の様子を尋ねれば、自分の目で確かめる。必要なら首を動かし、見つけたことを声で返す。そんな一連のやり取りを、ばらばらの機能ではなく、一つのロボット体験として届けたいと考えています。

でも、特定のカメラやAIにしか使えない仕組みでは、そこで成長が止まってしまう。だからYatagarasu 2では、目も、耳も、口も、記憶も、考えるAIも、役割ごとに交換できる構造を目指します。

現在は、その土台となる要件と設計を作っている段階です。動作する配布物や導入手順はまだありません。原型となるYatagarasu 1を動かし続けながら、Yatagarasu 2は別の環境で検証していきます。
