# System Design FIX Approval

横展開後に追加されたcanonical contractをPilot承認へ便乗させないため、system design FIX時に
全`accepted` Design ID集合を独立審査とPrimary承認へ固定します。

| Field | Value |
| --- | --- |
| Artifact type | `system-design-fix-approval` |
| System design revision | `unfixed` |
| Accepted Design IDs Ref | `unfixed` |
| Accepted Design IDs SHA-256 | `unfixed` |
| Architecture review Ref | `unfixed` |
| Review SHA-256 | `unfixed` |
| Primary approval Ref | `unfixed` |
| Approval SHA-256 | `unfixed` |
| Status | `draft-not-runnable` |
