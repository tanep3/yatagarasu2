# Yatagarasu 2

## 見守りカメラを、目・耳・口を持つAIロボットへ。

見守りカメラには、周囲を見るカメラがあります。人の声を聞くマイクがあります。こちらへ声を返すスピーカーもあります。首を動かせる機種なら、自分で見る方向まで変えられます。

だったら、そこへAIの神経と思考をつないだらどうなるだろう？

声をかければ目を覚ます。頼まれた方向を見て、必要なものを確かめる。人が普段使っているアプリやデータにも、Skillを通して手を伸ばす。そして、見つけたことや考えたことを、自分の声で返す。

Yatagarasu 2は、見守りカメラに便利な機能を足すだけのプロジェクトではありません。目、耳、口、身体、記憶、AI、そして外のアプリを交換しながら、一つのロボットとして育てられる神経・思考基盤を作るプロジェクトです。

## 何がうれしいの？

- 声でもWebでも、同じYatagarasuへ頼めます。
- カメラやAIを一つの製品へ縛らず、役割ごとに交換できます。
- SBERTによる意味の反射で、質問に合うAI（LLM）や推論サービス（Provider）を高速に選び分けます。
- Skillによって、AIはロボットの内側だけでなく、人が使うアプリやデータともつながれます。
- 動いたか分からないときは、分かったふりをしません。確認できた事実と推測を分けて扱います。

この構造は、将来の別のカメラ、複数の目、別のマイクや声、さらには異なる身体へ育てるための土台になります。ただし、まだ対応機器や完成時期を約束する段階ではありません。

## 今は、どこまでできているの？

Yatagarasu 2は、いま要件と設計を作っている段階です。今すぐ導入できる完成品ではありません。

一方、原型となるYatagarasu 1はすでに実機で動いています。Yatagarasu 2は、そこで発見した機能、速度、失敗、不確実性を受け継ぎます。ただし、動いているYatagarasu 1へ未完成のコードを混ぜることはしません。別の環境で、世界の構造から作り直します。
